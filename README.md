# Pitchord

用于校对歌曲歌词时间的本地桌面编辑器。本阶段完成句级和字级时间编辑。界面规范见 [design.md](./design.md)。

## Windows 完整便携包

Release 只提供一个完整压缩包：`Pitchord-<版本>-windows-x64-complete.zip`。将其中的 `Pitchord` 文件夹解压到任意本地磁盘和任意可写位置，再双击 `Pitchord.exe`；不需要安装程序、系统 Python 或额外模型下载。

专用 Python、分析依赖、模型和缓存位于程序根目录的 `environment`，应用状态位于同级 `data`。移动整个 `Pitchord` 文件夹即可迁移软件，删除整个文件夹即可完整卸载。歌词工程保存在用户新建工程时选择的位置，不会因为删除程序文件夹而自动删除。“分析环境 → 管理存储”也能识别并清理旧版本遗留在 `%LOCALAPPDATA%\Pitchord` 的分析数据。

开发时可以运行：

```bash
pnpm desktop:start
```

生成完整便携压缩包：

```bash
pnpm desktop:package
```

构建过程先生成可搬动的完整环境，再把应用和 `environment` 一起压缩。中间目录 `offline-analysis` 不提交到 Git；依赖版本由 `scripts/analysis-lock-win-x64.txt` 固定。

## 开发版网页预览

需要 Node.js 20.19+ 或 22.12+ 与 pnpm。

```bash
pnpm install
pnpm dev
```

打开终端显示的本地地址。`pnpm build` 构建，`pnpm test` 检查歌词编辑规则。

## 当前流程

1. 新建工程，指定名称和存放位置（默认在“文档/Pitchord Projects”）；然后导入音频或视频。原文件会复制到工程的 `media` 文件夹，不上传媒体。
2. 导入 LRC 文件或粘贴普通歌词。普通歌词会先按媒体时长均分，随后人工校对。
3. 在句级视图编辑文本与时间。拖动歌词矩形或左右手柄，连续选中后合并；点击时间轴或按空格暂停可设置全局辅助线，边界靠近时自动吸附，分割时也直接采用该位置。文字分割默认参考中英文标点和空格。删除只删除标注。
4. 在字级视图逐字调整。初始字界是均分建议，所有字界都限制在所属句内。
5. 双击已选中的时间块进入范围调整并循环试听。拖动结束边界时，一次拖动过程中只更新循环终点，不会反复跳回；按 Enter 保存，按 Esc 放弃。撤回与重做支持编辑操作，也可保存完整 `.pitchord.json` 项目或导出句级 LRC。
6. 完整便携包已带有专用 Python、分析依赖和人声分离模型，可以直接运行人声分离。原声、纯人声和纯伴奏可分别开关、调节音量与叠加试听；视频画面保持不变。连续音高只从纯人声轨生成，音高轨会叠加到时间轴，并按字级范围显示音名和基础运动类型。源码开发版仍可在“分析环境”中单独准备所需环境。

桌面工程会自动保存 `project.pitchord.json`，并把原媒体放在 `media`，把人声分离的 WAV 放在 `analysis`。歌词另存于 `lyrics/current.lyrics.json` 和 `lyrics/current.lrc`；历史版本在 `lyrics/backups`，导入的 LRC 或粘贴原文在 `lyrics/sources`。点击“歌词备份”可查看文件，点击“恢复歌词”可选择一个历史 JSON 版本恢复；恢复本身也可撤回。点击“工程文件夹”可直接用其他播放器试听原媒体、人声与伴奏。打开工程时会自动恢复保存的媒体与分析音轨。网页预览仍使用浏览器本地歌词草稿。

## 目前边界

- 字级初始范围是可编辑的时间建议；连续音高使用本地自相关基线，适合人工复核，不等同于最终的歌声专用模型。文字变化时，未变化的首尾字尽量保留其时间；必要时会重新分配时间，需复核。
- “运行人声分离”直接处理工程内的原始媒体，不会再次要求选择文件。桌面版调用 `scripts/separate-vocals.py`，使用 Demucs 同时生成纯人声和纯伴奏 WAV，并保存到工程的 `analysis/separation-*`。分离音轨用同一个 Web Audio 时钟混音，切换开关或音量不重启音频；人声和伴奏可增益到 200%。也可以使用“导入外部人声结果”载入已有的人声 WAV/MP3。桌面包已内置 FFmpeg/FFprobe，可直接处理 MP4 等视频。
- 分析环境和模型不写入工程，也不修改系统 Python 或 PATH。完整便携包直接使用 `<Pitchord 根目录>/environment` 中的现成环境；源码开发模式继续使用 `%LOCALAPPDATA%/Pitchord`，避免把开发环境混入仓库。当前完整环境约占 1.3 GiB，后续加入模型时体积会增加。开发者仍可在“高级：选择已有 Python”中指定环境。当前便携环境支持 Windows x64，CPU/GPU 环境选择和更多模型包属于后续增强项。
- 当前连续音高是可解释的本地自相关分析；歌声专用音高模型、声区（真声/假声/混声）标注和更强的歌词强制对齐仍属于后续增强项。
- 分割时间可由播放头指定；未指定时参考句中附近的波形音量低谷。它仍需人工试听确认。
- LRC 只保存句级起点。完整句界、字界与人工调整保存在 `.pitchord.json` 中。
- 视频波形依赖浏览器对音轨格式的解码支持；无法提取波形时，视频仍可播放并编辑时间标注。
